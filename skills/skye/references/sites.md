# 三個網站

網站用**你（AI）自己內建的瀏覽器**操作，沿用同事在那個瀏覽器的登入（要登入時由同事自己登入）。下面的「不可逆網址」是**不可以按、不可以開的網址**：用你自己的瀏覽器時，看到連結或按鈕會導向這些網址就不要按（只有同事明確要求公開時，請同事本人按）。選用的 SKYE 瀏覽器工具則用每站的 `profile` 名稱，第一次 `browser_open` 時一併帶上該站的 `irreversible_patterns`（只能新增，不能移除），由 SKYE 擋下。只能用在公司網站清單（新官網、Canva；舊官網待老闆 Skye 提供網址）。

## Canva（www.canva.com）

- 設定檔：`canva`（Google 登入的彈出視窗由同事操作）
- 已知：編輯器大部分是 canvas，很多動作 DOM 做不到；做不到時**停下來說明卡在哪**，不要改用截圖或座標點擊。
- 匯出 PNG：用你的瀏覽器下載，存到下載資料夾後，請 SKYE 用 `search_files` 找到檔案並回報大小（需要時再用 `copy_verified` 放到指定資料夾）。用 SKYE 的瀏覽器工具時改用 `browser_download`（`effect: "write"`），會回傳路徑、大小、SHA-256。
- 不可逆網址（先登記）：`*share*`、`*publish*`、`*delete*`、`*trash*`（待實測補充）。
- 規則：設計留在帳號，不分享、不刪除。
- 待老闆 Skye 實測後補：建立設計、改標題、加文字的可行做法。
