# 交接格式（Word 行程 → 上架資料）

> 草案：欄位依 2026-10-16 新官網上架實測整理，**待老闆 Skye 確認公司正式格式**後替換。

讀完 Word 後，先整理成下表給同事確認，**同事說「對」才開始上架**。缺的欄位標「（缺）」並問同事，不要自己編。

| 欄位 | 說明 | 例 |
| --- | --- | --- |
| 團號 | 公司團號，英數，用來比對防重複 | `PEK20B` |
| 標題 | 官網顯示標題 | 西伯利亞大鐵路（蒙古＋貝加爾湖＋莫斯科）20 日 |
| 天數 | 整數 | 20 |
| 地區／主分類 | 依後台選單的文字 | 歐洲 / 東歐 |
| 國家 | 逗號分隔 | 蒙古、俄羅斯 |
| 出團日期 | 有幾個列幾個；Word 沒有就標（缺） | 2027-05-10 |
| 售價 | 依 Word；沒有就標（缺） | |
| 列表描述 | 1–2 句，官網列表顯示 | |
| 每日行程 | 第 N 天：標題＋內容（照 Word，不改寫事實） | |
| 照片清單 | 列表圖 1 張＋每日照片（檔名、對應第幾天） | |
| 啟用 | 一律「否」 | 否 |
| 熱門／精選／出團快訊 | 一律「否」，除非同事指定 | 否 |

## 寫給同事確認時

- 用表格呈現，標出你**推測**的欄位（例如從標題推天數）。
- 數字、日期、價格照 Word 原文，不換算、不四捨五入。
- 一份 Word 有多個團號時，一團一張表，逐團確認。
